# Online Student Details System

A web-based Student Details Management System built using PHP, MySQL, HTML, CSS and JavaScript.

## Features

- Student Login
- Admin Login
- Student Profile
- Attendance Management
- Test Marks Management
- Leave Management
- Student Performance
- Admin Dashboard
- Student Dashboard

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- GitHub
